Theft / Exfiltration / Persistence / Lateral Movement / Obfuscation

  • **Exfiltration:** External URLs are mostly documentation, papers, GitHub references, and a survey link. There is no evidence of HTTP upload, webhooks, raw IP C2, paste/drop services, or attacker-controlled exfiltration endpoints.

  • **Persistence:** The .bashrc reference is user guidance for disabling tips. No cron, systemd, launch agent, shell-profile modification, or self-reinstall loop was identified.
  • **Lateral movement:** No evidence of Kubernetes, Docker socket, cloud metadata, CI/CD token abuse, or GitHub Actions workflow injection was found.
  • **Obfuscation/loader:** The exec() usage appears to be for dataclasses-style dynamic function creation in _create_fn. There is no visible base64/zlib/marshal/eval payload loader or obfuscated downloader stub.

Distribution Integrity Anomalies

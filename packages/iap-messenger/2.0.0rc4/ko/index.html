사전 탐지 항목들은 검토 범위 내에서 악성 공급망 행위로 보기 어렵습니다.

  • .gitignore의 .pypirc는 무시 대상 파일명 언급일 뿐, 토큰 탐색/읽기/전송 근거가 없습니다.
  • .gitlab-ci.yml의 PYPI_TOKEN, twine upload는 태그 릴리스 시 PyPI 배포를 위한 일반 CI 설정으로 보입니다.
  • .github/workflows/build.yml의 wheel/sdist 수집 및 PyPI trusted publishing은 일반 배포 파이프라인으로 보입니다.
  • listener.py의 os.system("touch /tmp/running")는 단독으로는 악성 설치 후 실행, 절취, 지속성, 은닉과 연결되는 근거가 부족합니다.
  • ddl.py, listener.py의 ZMQ/NATS 네트워크 통신은 패키지 기능상 메시징/데이터 전달 로직으로 보이며, 임의 C2나 비밀정보 유출 근거는 확인되지 않았습니다.

자동 실행 경로

설치 시 또는 Python 인터프리터 시작 시 자동 실행되는 악성 경로는 확인되지 않았습니다.

  • 제공된 파일에서 .pth, sitecustomize.py, usercustomize.py, setup.py 기반 실행 근거는 확인되지 않았습니다.
  • ddl.py의 실행 예제는 if __name__ == "__main__": 가드 아래에 있어 import/install 시 자동 실행 근거가 아닙니다.
  • listener.py는 import 시 asyncio.create_task를 래핑하는 부수효과가 있으나, 현재 증거만으로는 악성 공급망 자동 실행 또는 페이로드 실행으로 보기 어렵습니다.
  • 일반 CI 빌드/배포 스크립트는 저장소 이벤트에서 실행되는 정상 배포 동작으로 보이며, 패키지 설치자 환경에서 자동 실행되는 악성 경로 증거는 없습니다.

절취/전송/지속성/측면이동/은닉

  • **Credential harvesting:** 광범위한 환경변수 수집, .env, SSH 키, 클라우드 자격증명, CI/CD secret, 지갑 파일 탐색 등의 코드 증거는 확인되지 않았습니다.
  • **Archive staging / exfiltration:** 수집 파일을 압축/스테이징하거나 외부 공격자 엔드포인트로 업로드하는 증거는 확인되지 않았습니다. CI의 dist 산출물 병합은 정상 배포 작업으로 보입니다.
  • **Persistence:** cron, systemd, launch agent, shell profile 수정, 재설치 루프 등 지속성 메커니즘은 확인되지 않았습니다.
  • **Lateral movement:** Kubernetes 서비스어카운트 토큰, Docker socket, 클라우드 metadata, GitHub Actions 토큰 탈취/워크플로 주입 등 측면이동 증거는 확인되지 않았습니다.
  • **Obfuscation / loader:** base64/zlib/marshal/eval/exec 기반 로더, 암호화 페이로드, 다운로더 스텁, 난독화된 RAT 선택 로직은 확인되지 않았습니다.

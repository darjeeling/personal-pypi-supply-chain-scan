  • Exfiltration/staging: 수집 파일 아카이브 생성, base64/압축 staging, 웹훅 또는 공격자 제어 endpoint로 업로드하는 증거가 없습니다.

  • Lateral movement: Kubernetes service account, Docker socket, cloud metadata, GitHub Actions 토큰 탈취/워크플로 주입 등 개발·CI·클라우드 측면이동 증거가 없습니다.

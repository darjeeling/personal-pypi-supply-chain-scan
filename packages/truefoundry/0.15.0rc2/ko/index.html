  • 일반 CLI/console entry point 또는 사용자가 명령을 실행해야 동작하는 배포/빌드/패치 기능은 악성 자동 실행 근거로 보지 않았습니다.

절취/전송/지속성/측면이동/은닉

  • **Credential harvesting:** 광범위한 환경변수 수집, .env, shell history, SSH private key, cloud credential 파일, CI 토큰 등을 탐색·수집하는 코드 근거는 확인되지 않았습니다. 사전 스캔의 OPENAI_API_KEY, AWS/SQS credential, SSH public key, kubeconfig 언급은 모델 스키마/설정/문서성 필드로 보이며 절취 증거와 연결되지 않았습니다.
  • **Archive staging / exfiltration:** tarfile, zipfile, shutil.make_archive, requests.post 등의 사용 흔적은 있으나, 검토된 맥락상 배포 소스 패키징, artifact 처리, 스토리지 업로드 등 정상 SDK/CLI 기능으로 보이며 비밀 수집 후 외부 C2로 전송하는 흐름은 확인되지 않았습니다.
  • **Persistence:** systemd, cron, launch agent, shell profile 수정, startup folder, 백그라운드 폴링 백도어, self-reinstall 근거는 확인되지 않았습니다.
  • **Kubernetes/CI/cloud lateral movement:** Kubernetes service account token 경로 상수 및 kubeconfig 관련 문구가 있으나, 워크플로/배포 기능 맥락이며 토큰 탈취, kube-system 접근, privileged pod 생성, hostPath/Docker socket 남용, CI 토큰 재사용 근거는 확인되지 않았습니다.
  • **Obfuscation/loader:** eval/exec/compile, base64/zlib/marshal 기반 staged loader, 암호화 페이로드, 다운로더 드로퍼, 자가 삭제 로직은 확인되지 않았습니다. 사전 스캔의 regex/xor/base64-like 탐지는 검증상 일반 검증 로직 또는 URL 내 해시로 보입니다.
  • **Network indicators:** 사전 스캔상 raw public IP, 의심 C2 endpoint는 없으며, 확인된 도메인은 주로 truefoundry.com, 문서 사이트, GitHub 참고 링크, Docker/HuggingFace 등 정상 서비스로 보입니다.

배포 무결성 이상

  • .gitignore가 sdist에 포함된 점은 확인되지만, 단독으로 악성 공급망 징후로 볼 만한 숨김 payload 또는 실행 로직은 확인되지 않았습니다.
  • 예상 밖 native binary, 숨김 실행 페이로드, typosquatting 정황, 공격자 제어 저장소/도메인, wheel/sdist 불일치 증거는 제공된 자료에서 확인되지 않았습니다.
  • 갑작스러운 의존성 삽입 여부는 제공된 텍스트만으로 판단할 근거가 없습니다.
